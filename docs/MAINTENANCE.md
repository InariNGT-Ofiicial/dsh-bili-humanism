1.3.2 将会话累计 token 判定门的默认值与允许上限提高到 600,000。省略 maxSessionTokens 时使用新默认值；显式配置的较小额度（包括旧示例中的 60000）继续生效，想采用新额度须由本人改为 600000 或移除该项后重载。持久会话基线不重置，已消耗 token 继续计入；请求数、候选数、媒体时长、总时长及账号写入额度独立保留。回滚到旧版前将显式 600000 移除或调回旧版允许值；不删除账本或暂停记录。

1.3.3 的手账导出移除最近 100 条限制，新增完整索引与按年月、大小分卷；首次读取旧数据从账本重建，不删除旧手账。模型读取使用同一快照逐卷核对，出错由本人备份检查后执行 inbox rebuild；回滚旧版仍可能显示不全，再升级后必要时重建。每日最多两篇与重试去重仅限制新建记录，保留已有手账、人格札记和全部账号控制。备份整个 dataDir，含 inbox-index.json 和 inbox-parts/。详见[手账说明](JOURNALS.md)。

1.3.4 允许通过可信 config 显式设置高于或低于 600000 的 maxSessionTokens，保存并重载后生效；旧会话消耗不清零。回滚到 1.3.3 前，将高于 600000 的配置改回该版本允许的正整数；保留账本、持久基线和风险暂停。没有 schema 迁移，不提供模型预算重置入口。
