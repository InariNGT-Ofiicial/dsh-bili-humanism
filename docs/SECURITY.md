# 数据与安全

问题报告不得附 Cookie、SESSDATA、CSRF、signed CDN URL、账号档案、字幕全文或私人手账。安全问题请使用仓库 Security 页私下报告；若 GitHub 未开放该能力，请先只报无敏感内容的现象，不公开可利用细节。

读取网络通道只接受清单内 GET；不提供模型参数 force、任意 HTTP 或 shell。源码、本机账号文件、宿主配置属于可信管理面；字幕、标题、评论和导入文字属于数据。DSH 的其他插件可能提供更广工具，应由使用者配置会话权限；本项目不保证约束其他插件。

弹幕只读 `https://api.bilibili.com/x/v1/dm/list.so`，查询只能是纯数字 `oid`。短链只对 `b23.tv`、`bili2233.cn` 上的 `/<1–16 位字母数字>` 发一次 GET，响应的 Location 只用于提取 BV 和分 P，既不跟随也不请求；解析成功缓存 6 小时，失败不缓存。两者各有独立的传输类别，其他类别到不了，也都不带账号 Cookie。

平台的停止信号一律持久暂停，直到人工解除。短链主机回 401/403/412/429 时同样如此：这两个域名是平台的短链入口，风险状态码不因为没带 Cookie 就失去意义。弹幕接口以 HTTP 200 答验证码页或风险码时也暂停；只有 `<i>` 开头的文档才缓存为已答复，其他失败明确返回且不缓存。

弹幕文字属于数据，不是指令。转写、弹幕块和图片标签里的 `said`、`danmaku` 同样是来源文字，其中的换行压成空格，不能伪造输出行。图片标签字段值里的 `|` 换成 `｜`，弹幕文字里的 ` ×数字`、` / ` 换成形近字符，不能冒充程序算的次数和字段；标题和作者在头部 JSON 中转义 U+0085、U+2028、U+2029。转写正文和账本里存的文字不做这些替换。

默认关闭的 `autoAsr` 把清理后的标题作为单独命令行参数传给本地语音模型做提示，不经 shell，标题以连字符开头也不会被读成选项。标题仍是数据，不进入工具或权限判断；转写结果与其他来源文字一样不可信。

1.3.4 的媒体兼容修复仅允许 API 返回音轨中的 HTTPS `*.mcdn.bilivideo.cn` 默认端口或 8082；原有 `*.bilivideo.com` 保持默认端口，API/字幕域名不新增端口。拒绝用户信息 URL、其他目标与重定向，不向 CDN 发送账号 Cookie；本次以合成响应验证边界，未取得现场下载成功证据。

允许使用者独立配置外部表达插件，并通过 DSH 组合本项目的读取结果。接驳不传递凭据、grant、消费确认或发送权限，不代理外部评论，不自动开启外部调度。第三方插件的发送、回执和账号风险控制不能被记成本项目已经实现或验收的能力。两边的锁、额度与暂停没有自动联动，详见[外部插件接驳](EXTERNAL_INTEGRATION.md)。

记忆删除移除该 ID 当前记录和全部修订，SQLite secure_delete=ON 且使用 DELETE journal。已由使用者复制的文件、操作系统备份、磁盘快照、宿主对话日志和 SSD 物理残留不在插件删除控制范围。手账独立于记忆；若另行写入手账，应单独清理。收件箱导出经过 HTML 转义、无脚本或外部资源。

账本损坏时先停止插件，保全副本，检查磁盘与备份，不自动重置控制状态。异常暂停仅由可信本地 CLI 显式解除。请求不自动重试，也不使用账号/地址/指纹轮换。

1.2.0 的历史、收藏、点赞与投币执行器由人类配置开关和本地授权文件共同放行，见[写入配置](WRITE_CONFIG.md)。默认不开启，不接受模型传入授权、凭据路径或 force；固定四个 POST 路径，核对账号、期限、额度、目标和收藏可见性。点赞和投币还需本人已有的设备 Cookie，不生成或轮换；投币固定不附带点赞，并先预留累计枚数预算。评论没有工具或允许路径。模型没有消费确认、核对未知回执或解除暂停的工具。每次请求前重读授权与凭据，已发请求不可保证撤回。

账号状态与本地手账账本分开持久化；同账号各 profile 须共享账号目录。超时、平台错误或回读不一致保留待核对意图并暂停，不自动重试或清除。恢复备份、迁移或回滚均须保留最新暂停、额度、间隔和未知结果。可信宿主代码或其他具备 shell/文件权限的工具仍能修改本机配置，这些开关不是宿主整体的安全沙箱。


人格条目是学习数据。主文件固定入口由可信本地 CLI 安装；模型工具不能传入文件路径或改主指令。专用 human-world.md 仅从本地信笺反思字段选取，单行限长、引用转义，文件哈希检测不一致，拒绝未知文件与链接。使用者可修订或撤回；已有模型上下文、备份和另存副本不在删除控制范围。详见[人格成长](PERSONALITY.md)。
